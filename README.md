标题：客户流失分析

简介：900+客户数据，分析流失率与消费水平、年龄、账户经理的关系

核心结论： 经过分析我判断

1.缺乏老客户运营机制，老客户流失率高，8年以上老客户甚至有40%流失率

2.有经理反而流失率更高，19%流失率，高出5个百分点

（1）	客户出了问题、快流失了才给配个经理，但已经晚了

（2）	经理服务质量不行，配了但没起到留存作用，甚至可能因为对接体验差加速流失


3.站点大于9之后，顾客流失率大幅增加，其中12~15站点处流失全部更多。
